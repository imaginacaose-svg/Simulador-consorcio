# Simulador Consórcio

Sistema completo de simulação de consórcios com geração de propostas personalizadas.

## 🚀 Funcionalidades

- ✅ 3 abas no painel admin (Proposta, Taxa Administrativa, Lance Total)
- ✅ Página de proposta para o cliente
- ✅ Cálculos financeiros (2,5% a.m., 60 parcelas, Tabela Price)
- ✅ Modalidade Parcelinha
- ✅ Lances (embutido + livre)
- ✅ Integrações (Email, WhatsApp, Instagram)

## 🛠️ Tecnologias

- React 18 com TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## 📦 Instalação

npm install
npm run dev
